# SIMBAD-object-finder
Sort through VOTable files and apply criteria to find target objects in the night sky.
# Instructions
Install [Pluto.jl](https://plutojl.org/en/docs/install/) and run the [main file](SIMBAD_rewritten.jl) in an interactive notebook.
## Note
2024-11-24 Current version only supports local upload of VOTable files - in the format produced by [SIMBAD](https://simbad.u-strasbg.fr/).
